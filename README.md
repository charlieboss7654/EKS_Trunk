# EKS Hide in Trunk

This script allows players to hide inside the trunk/boot of a vehicle using `ox_target`. Perfect for immersive roleplay scenarios such as kidnappings, hostage situations, or sneaky getaways.

## Features:

- Third-eye option to **Hide in trunk** when aiming at the boot
- Trunk automatically opens when entering/exiting
- Press **F** to exit the trunk
- On exit, the player reappears just behind the vehicle
- Works with all vehicles that have a boot
- Safe handling for despawns, death, or server restarts

## Installation:

1. Drag and drop the folder into your `resources/` directory  

2. Add the following to your `server.cfg`:

ensure EKS_HideInTrunk

3. Make sure your `server.cfg` also includes:

ensure ox_lib
ensure ox_target


## Controls:

- Third-eye (ox_target): Aim at the trunk ? *Hide in trunk*
- F: Exit the trunk
